# Return & Refund Knowledge Base — Product-Specific Rules (Part 2)

This document complements the main Return & Refund KB (general eligibility, process, and timelines) with rules specific to each product category in the catalog. Use this to determine return type (refund vs. replacement-only), condition requirements, and category-specific exceptions.

## Smart Home Devices

**Q: Can I return my Smart LED Bulb 9W or WiFi Smart Plug?**
A: Yes, within the standard 7-day window if unused/uninstalled and in original packaging. If the bulb was fitted and later found to have a manufacturing defect (e.g., won't connect to WiFi after all troubleshooting steps), it qualifies for free replacement rather than return-for-refund, since these are low-cost items where reshipping a working unit is faster than a refund cycle.

## Kitchen Appliances

**Q: Can I return my Electric Kettle, Air Fryer, Microwave, Induction Cooktop, or Mixer Grinder if I just don't like it?**
A: Yes, within 7 days, provided the item is unused, uncooked-in, and free of food residue or burn marks. Items showing signs of cooking/use (oil residue, scorch marks, water stains inside) may be rejected at quality check as "used," not eligible for change-of-mind return — though still eligible for a defect claim if genuinely faulty.

**Q: My Microwave/Induction Cooktop arrived with a manufacturing defect (sparking, error code, no heat).**
A: These qualify for free replacement or refund regardless of the 7-day general window being close to expiry, since it's a safety-related defect — route as "Defective on Arrival," not "Change of Mind."

## Large Appliances

**Q: Can I return my Refrigerator 250L or Washing Machine 7kg for a refund if I changed my mind?**
A: No — per the general policy, large appliances are on a **10-day replacement-only window** for manufacturing defects. Change-of-mind returns are not accepted for these categories once delivered, due to installation and logistics costs. If truly unopened/unboxed and pickup can be arranged before any installation occurs, escalate to a human agent — this is a case-by-case exception, not standard policy.

**Q: My refrigerator/washing machine has a defect discovered after the 10-day window.**
A: After 10 days, defects are handled under the **Warranty & Repair** process (repair or replacement via technician visit), not the Return & Refund process. Refer the customer to that document.

## Climate Control

**Q: Can I return my Split AC 1.5 Ton?**
A: Treated the same as large appliances — **10-day replacement-only window** for defects, no general change-of-mind return once installed. If the AC has not yet been installed by a technician, cancellation/return before installation is more straightforward — check installation status first.

**Q: Can I return my Tower Fan, Room Heater, Air Purifier, or Ceiling Fan?**
A: Yes, standard 7-day return window applies since these are smaller, self-installable items — not treated like split ACs. Ceiling fans that have already been mounted/wired by an electrician are only eligible for defect-based replacement, not general return, due to installation.

## Entertainment & Audio

**Q: Can I return my LED TV 43-inch?**
A: Yes, within 7 days if the unit is unused, screen is undamaged, and original packaging/accessories (remote, stand, cables) are included. **Dead pixel policy**: a small number of dead/stuck pixels (typically fewer than 3-5, per manufacturer tolerance) is considered normal manufacturing variance and not grounds for return — only qualifies if pixel count exceeds tolerance or a visible defect (lines, discoloration) is present.

**Q: Can I return my Soundbar or Bluetooth Speaker?**
A: Yes, within 7 days if unused and undamaged. These are not hygiene-sensitive items (unlike earbuds/headphones), so opened-but-untested units can still be evaluated for return, though physical signs of use (scratches, worn buttons) may affect eligibility.

**Q: Can I return my Wireless Earbuds or Over-Ear Headphones?**
A: Only if **unopened and unused**, due to hygiene reasons (both are worn in/on the ear). If the seal is broken but the product is defective (won't pair, one side dead, no sound), this qualifies as "Defective on Arrival" and is handled separately from a general hygiene-based rejection — defect claims are accepted even if opened, but general "didn't like it" returns are not.

## Mobile & Wearables

**Q: Can I return my smartphone?**
A: Yes, within 7 days, provided:
- No visible physical damage (scratches, cracks, liquid exposure).
- IMEI/serial number matches the original invoice.
- Device has been factory-reset by the customer before return (for their own data privacy) but is otherwise in working, unlocked condition.
- All original accessories (charger, cable, SIM tool, box) are included.
A device that has been activated with a different carrier lock or shows signs of being used as a daily driver for an extended period past the window is not eligible.

**Q: Can I return my Smartwatch or Fitness Band?**
A: Yes, within 7 days if the strap/band is unused and free of skin contact residue (hygiene consideration similar to earbuds, though less strict since it doesn't enter the ear/mouth). Defective units (won't charge, inaccurate sensors validated by troubleshooting) are eligible regardless of strap wear.

## Computing & Accessories

**Q: Can I return my Laptop 15.6-inch?**
A: Yes, within 7 days if unused, no visible damage, and the operating system has not been extensively configured/personalized (a light OS setup for testing purposes is acceptable; heavy use — installed software, personal files, extensive activity — may flag the return for additional quality review). All accessories (charger, manual, box) must be included.

**Q: Can I return my Wireless Mouse or Mechanical Keyboard?**
A: Yes, within 7 days if unused/undamaged. These are not hygiene-restricted like earbuds. Keyboards/mice showing wear (worn key caps, scratched mouse feet) from extended use may be rejected as "used," but individual malfunctioning keys/buttons qualify as a defect claim.

**Q: Can I return my Power Bank 20000mAh, USB-C Cable, or Wall Charger?**
A: Yes, within 7 days if unused and undamaged. **Important**: power banks showing any swelling, physical deformation, or heat damage should never be returned via standard courier pickup — flag these as a safety case and follow the hazardous-item return process (special handling), not a normal pickup request.

## Storage & Networking

**Q: Can I return my External Hard Drive 1TB or Pen Drive 64GB?**
A: These are **non-returnable once the security seal is broken or the device has been connected to a computer**, due to data-privacy and anti-fraud reasons (used storage devices can't be resold and pose data-wipe verification challenges). Unopened/unused units in sealed packaging are returnable within 7 days. Defective units (not detected by any computer, verified via troubleshooting) are eligible for replacement even if the seal was broken, since this is a defect claim rather than a change-of-mind return.

**Q: Can I return my Wi-Fi Router?**
A: Yes, within 7 days if unused and undamaged, including original packaging and power adapter. A router that has been configured/connected to test connectivity is generally still eligible for return since this is standard verification, not "extended use" — but factory reset it before return to remove personal network credentials.

## Electrical & Power Backup

**Q: Can I return my Extension Board?**
A: Yes, within 7 days if unused and undamaged. Any unit showing scorch marks, melted plastic, or burn damage should be flagged as a safety-related defect and routed for priority replacement, not standard return processing.

**Q: Can I return my Inverter with Battery?**
A: Treated similarly to large appliances due to installation and weight — **10-day replacement-only window** for defects once installed. If not yet installed/wired by an electrician, a straightforward pickup return is possible within 7 days.

## Additional Home Appliances

**Q: Can I return my Water Purifier (RO)?**
A: If not yet installed (no plumbing/wall-mounting done), standard 7-day return applies. Once installed, it is treated like a large appliance — **10-day replacement-only window** for defects, not general change-of-mind, due to installation/plumbing involvement.

**Q: Can I return my Robot Vacuum Cleaner or Handheld Vacuum Cleaner?**
A: Yes, within 7 days if unused and undamaged, dust cup empty and clean. Units with dust/debris inside indicating use may be rejected as "used" for change-of-mind returns but remain eligible for defect claims (e.g., won't dock, no suction).

**Q: Can I return my Iron Box (Steam)?**
A: Yes, within 7 days if unused with no water residue or scorch marks on the soleplate. Units with visible burn marks from customer misuse are not eligible for return/refund, though a genuine heating-element defect (no heat at all when new) qualifies as Defective on Arrival.

## Personal Care

**Q: Can I return my Hair Dryer, Trimmer, or Electric Toothbrush?**
A: Only if **unopened and unused**, due to hygiene reasons — this applies strictly regardless of price point. If defective on first use (won't turn on, won't hold charge from new), this is handled as a defect claim, which may be accepted even with the seal broken, since the product was reasonably tested to discover the fault.

**Q: Can I return my Digital Weighing Scale?**
A: Yes, within 7 days if unused and undamaged — not hygiene-restricted like other personal care items, since it has no skin/mouth contact.

## Furniture & Lighting

**Q: Can I return my Study Table Lamp or LED Ceiling Light?**
A: Yes, within 7 days if unused/uninstalled and in original packaging. Once a ceiling light has been professionally wired/mounted, only defect-based replacement applies (not general return), due to the electrical installation involved.

**Q: Can I return my Sofa Set, Dining Table Set, Bed Frame, Wardrobe, or Bookshelf?**
A: Furniture falls under the same **10-day replacement-only window for manufacturing defects** as large appliances — no general change-of-mind returns once assembled, due to reverse-logistics costs for bulky items. If the item is still in its original flat-pack/unassembled packaging, a standard return may be possible — check assembly status first. Structural defects (cracked wood, bent frame, missing/wrong parts) qualify for free replacement or missing-part shipment, not a full return.

**Q: Can I return my Mattress Queen Size?**
A: Mattresses are hygiene-sensitive once unwrapped/used. Return is only accepted if the mattress is unopened in its original sealed/rolled packaging. Once unwrapped and slept on, only manufacturing defects (sagging, seam failure) discovered within the applicable warranty period are handled — via the Warranty & Repair process, not a general return.

**Q: Can I return my Office Chair?**
A: Yes, within 7 days if unassembled or only lightly test-assembled, undamaged, and all hardware/parts are included. Chairs assembled and used for an extended period are only eligible for defect-based replacement (e.g., gas lift failure, broken wheel), not general return.

## Quick Reference: Return Type by Category

| Category | Return Type |
|---|---|
| Smart home devices, kitchen appliances, TVs, soundbars/speakers, mouse/keyboard, cables/chargers, routers, extension boards, digital scale, lamps/ceiling lights (uninstalled) | Standard 7-day return (refund or replacement) |
| Earbuds, headphones, hair dryer, trimmer, electric toothbrush | Return only if unopened/unused; defects accepted even if opened |
| Storage devices (HDD, pen drive) | Non-returnable once seal broken/connected, unless defective |
| Smartphones, laptops | 7-day return with factory reset/no personalization required |
| Large appliances (fridge, washing machine, AC), inverter, water purifier (once installed), furniture (once assembled), mattress (once unwrapped) | 10-day replacement-only window for defects; no change-of-mind return |

## Escalation Trigger for This Document
Escalate to a human agent if:
- Item falls into a gray area (e.g., "lightly used" appliance where use vs. defect is disputed).
- Safety-related defect found during return inspection (swelling battery, scorch marks, sparking).
- Large appliance/furniture return requested outside the replacement-only window with no clear defect.
- Customer disputes a "used" classification at quality check.
